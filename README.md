# Sunny's Journal

An interactive learning journal for MSIT454, built with HTML, CSS, and JavaScript.

## Explore
https://supersunny7.github.io/sunny-learning-journal/

Move the pointer to explore the gaze interaction. Click objects to play chapter animations, or use Next to skip to the next reading pose. Open the book, cup, globe, and jacket notes. Back returns to the previous chapter. Still view is available in the options menu.

Topics: The Phoenix Project, DISC S style, The Culture Map / Germany, and future learning in tech and data.

## Run locally
Requires Node.js. Run `node server.cjs` and open http://127.0.0.1:5424/ .

## Media and sources
Character images and videos were AI-generated with image-generation tools and Seedance. Video derivatives are included for playback; no classroom documents, personal reports, credentials, or original source PDFs are included. The globe is illustrative, not an accurate map. The separate Germany map uses Natural Earth public-domain data. The Phoenix Project reflections are paraphrases, not the book text. Research links are provided in the Germany notes.

This is a personal course reflection and interactive prototype. Generated media can contain small pose and texture changes. Mobile/Safari behavior may differ. No license is granted to third-party source works.
